# 報告模板 (Report Template)

每份報告固定結構，中英對照（每段中文後面直接跟英文段），中文 100–1000 字，英文等量。

---

## 標題：{主題}（{YYYY-MM-DD HH:MM} UTC）
# Title: {English Title} ({YYYY-MM-DD HH:MM} UTC)

### 主題 / Topic
一句話點出範圍與問題。
One sentence on the scope and the question addressed.

### 核心發現 / Key Findings
3–5 條，每條一行開頭加 **標籤**。只寫有來源支撐的事實。
3–5 bullets, each prefixed with a bold **label**. Facts only — every bullet must be traceable to a source.

### 潛在影響 / Potential Impact
對工程/產業/人類福祉的實際意義。明確標註推論。
Practical significance for engineering, industry, or human welfare. Mark inferences explicitly.

### 來源依據 / Sources
- 機構/作者 — 標題 — 發布日期 — URL
（至少 2 個獨立來源；單一來源須標註局限 / At least 2 independent sources; note the limitation if there is only one)
- Org/Author — Title — Date — URL

### 簡評 / Commentary
可信度評估、爭議點、資料缺口、下一步。
Confidence assessment, contested points, data gaps, next steps.
